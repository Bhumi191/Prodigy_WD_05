#  Weather Studio

 Weather Studio is a responsive and visually focused weather dashboard designed to present live weather information through an elegant, editorial-style interface.

Instead of relying on standard weather icons, the application uses dynamic illustrated weather scenes, atmospheric backgrounds, animations, and theme changes to visually represent different weather conditions.

## Features

- Live weather data using the Open-Meteo API
- City-based weather search
- Current location weather detection
- Dynamic weather themes
- Animated weather scenes
- Weather-specific visual environments
- Sunny, cloudy, rainy, snowy, foggy, and storm themes
- Animated sun and atmospheric rays
- Layered cloud animations
- Animated rainfall
- Animated snowfall
- Moon and star scene
- Atmospheric fog effects
- Weather-dependent color palettes
- Current temperature and feels-like temperature
- Humidity information
- Wind speed
- Atmospheric pressure
- UV index
- Visibility information
- Sunrise and sunset timings
- Next 12 hours forecast
- Five-day weather forecast
- Responsive layout for desktop, tablet, and mobile
- Interactive search functionality
- Geolocation support
- Smooth transitions and hover effects

## Design

The interface follows a soft editorial design approach rather than the conventional weather dashboard style.

The visual system uses:

- Warm ivory backgrounds
- Soft pastel color palettes
- Cream and powder-blue tones
- Sage green accents
- Lavender storm themes
- Layered gradients
- Rounded glass-like surfaces
- Editorial typography
- Organic shapes
- Atmospheric illustrations
- Subtle animations

Each weather condition changes the overall visual environment of the application.

## Weather Visual System

### Clear Weather

The clear-weather scene includes:

- Glowing dimensional sun
- Animated sun rays
- Atmospheric rings
- Soft orange and cream gradients
- Layered landscape
- Floating visual elements

### Cloudy Weather

The cloudy scene includes:

- Multiple cloud layers
- Different cloud depths
- Animated cloud movement
- Muted green-gray sky
- Soft atmospheric lighting

### Rainy Weather

The rainy scene includes:

- Animated individual raindrops
- Layered clouds
- Cool blue atmosphere
- Reduced sunlight
- Atmospheric depth

### Snowy Weather

The snowy scene includes:

- Animated snowflakes
- Different snowflake sizes
- Slow drifting motion
- Icy pastel background
- Soft snowy landscape

### Foggy Weather

The fog theme includes:

- Reduced visibility
- Muted colors
- Atmospheric gradients
- Soft cloud layers
- Mist-inspired visual styling

### Storm Weather

The storm theme includes:

- Darker lavender atmosphere
- Heavy clouds
- Rain effects
- Lightning-inspired visual elements
- Strong atmospheric contrast

## APIs

### Open-Meteo

Weather and forecast information is retrieved from Open-Meteo.

The application uses weather data including:

- Temperature
- Apparent temperature
- Humidity
- Wind speed
- Atmospheric pressure
- Weather code
- UV index
- Visibility
- Sunrise
- Sunset
- Hourly forecast
- Daily forecast

Open-Meteo does not require an API key for this project.
